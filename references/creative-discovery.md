# Creative Discovery — Visual Opportunity Search

Load for open-ended ideation, weak concept fit, rejected style paths, or a request for genuinely different options. This is an **approach to searching**, not a fixed menu of what art should look like.

## Start with the actual visual opportunity

For Route A, revisit the real image before making material/spatial claims. For Route B, start from the subject or situation actually stated. Internally consider:

1. **Observe:** Which concrete feature has generative potential—silhouette, framing, empty space, perspective, repetition, scale, light, reflection, material, physical boundary, timing, or an implied action?
2. **Transform:** What visible relation could change—contact, continuity, substitution, occlusion, scale, recontextualization, viewpoint, typography as object, or a different visual medium? This list provides examples, **not required categories**.
3. **Style hypothesis:** Which photographic, painterly, graphic, physical, editorial, computational, or unusual material vocabulary would strengthen that transformation? A medium can be the main idea.
4. **Feasibility and elegance:** Is the visual event legible and attractive in a single image? Could its mechanism be illustrated without many contradictory spatial constraints?

Produce **one distinct creative seed per response by default**: cite the observed opportunity (or text brief), propose an imageable move, and invite real feedback. Keep explanation short enough for creative momentum. Never ask the user to choose among compatible components as though they are mutually exclusive.

## Novelty is a mechanism change, not a palette change

When the user dislikes an idea, identify what failed:

- **Mechanism:** concept lacks a convincing relationship to the source or stakes.
- **Aesthetic:** viable concept, but medium/styling is unconvincing.
- **Execution:** promising idea, but excessive physical complexity or poor image-model fit.
- **Context:** mood/narrative is wrong for the scene.

Then change the relevant underlying dimension. If the user repeatedly rejects “surreal plot twists,” stop inserting another plot twist under a new name. If they ask for an unfamiliar art style, propose a concrete material/medium treatment with a source-specific role rather than another generic filter.

Avoid recirculating house motifs (giant letters, portals, paper cutouts, one-color minimalist posters) merely because earlier projects used them. The same user's next image may require an opposite visual density or style.

## Style as testable hypothesis

Phrase a style suggestion as a relationship to the subject: “This material could make [specific existing shape or contrast] operate differently.” Do not treat historical art labels or popular design trends as sufficient execution instructions.

When a source or style reference is available, look for its **visual grammar** (brushstroke scale, media behavior, layering, edge treatment, color function, composition), not just a movement name. Use [visual-analysis.md](visual-analysis.md) for observed/fixed/variable/sample-specific distinctions.

## Offer optional visual comparison, never silent rendering

When verbal comparison is genuinely insufficient, suggest **2–3 differently conceived** preview directions. The previews should differ in visual logic/medium/composition, not just color. The user decides whether to request and authorize generation; a suggestion to compare does **not** invoke the image tool.

When a user explicitly asks for multiple directions or images, honor that request while following their generation trigger and count. For independent variations, use an equal generation budget and avoid judging success from one stochastic sample.

## Proactive convergence without a ritual

The concept is ready for a first convergence when **one main visual event**, its source-specific reason, and a style/medium hypothesis cohere. Announce that judgment briefly. Move to a few necessary choices (framing, size, text, material, occlusion). At the second convergence, state what the user has agreed to keep and change, then offer the requested prompt or execution step.

Do not converge because a quota of turns elapsed; do not stall with questions once the user has given enough. A novel user contribution can reopen any earlier decision.

## Anti-patterns

- Treating art movements as a list of fashionable filters.
- “Professional” prompting that accumulates P0 claims, arbitrary numbers, and detailed physical mechanics.
- Explaining a weak visual device until it sounds clever instead of changing the device.
- Repeatedly demanding A/B choices or permission to continue when the user already agreed.
- Making every collaborative chat a public Skill experiment or dataset.
